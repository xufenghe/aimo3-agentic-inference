# Changelog

All notable changes are documented here.

## 0.2.0 - 2026-09-11

- Add a dependency-free OpenAI-compatible Chat Completions backend.
- Add multi-round structured Python tool execution with local safeguards.
- Add reasoning-family diversification and deterministic per-attempt seeds.
- Add strict total deadlines, cooperative cancellation, and structured failure records.
- Add JSONL evaluation, privacy-conscious telemetry, endpoint diagnostics, and a CLI.
- Add end-to-end documentation, security guidance, contributor workflow, and package checks.

## 0.1.0 - 2026-09-11

- Publish the clean-room inference-control core with strict answer parsing, dynamic budgeting, concurrent attempts, early stopping, and uncertainty-aware consensus.

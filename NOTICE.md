# Notice and provenance

This repository is a clean-room, post-competition implementation of reusable inference-control patterns used across the public AIMO3 ecosystem. It is not a claim that the broader ideas of tool-integrated reasoning, parallel self-consistency, persistent Python workers, early consensus stopping, or entropy-based answer selection originated here.

The implementation was written from functional requirements and public technical descriptions. It does not redistribute the locally inspected submission notebook because that notebook substantially overlaps a public notebook lineage whose GitHub copy does not state an open-source license.

Public work that informed the functional design includes:

- Andreas Bisiadis, AIMO3 Solution: https://github.com/AndreasBis/AIMO3-Solution
- canqiang, Self-Consistency + TIR with Python-Verification-Weighted Voting: https://www.kaggle.com/competitions/ai-mathematical-olympiad-progress-prize-3/discussion/692656
- The AIMO3 competition and its public notebook ecosystem: https://www.kaggle.com/competitions/ai-mathematical-olympiad-progress-prize-3
- vLLM: https://github.com/vllm-project/vllm
- SymPy: https://www.sympy.org/

No model weights, competition datasets, private test material, or upstream notebook code are included.

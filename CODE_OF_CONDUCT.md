# Code of Conduct

## Our standard

We want this project to be a focused, welcoming place for people interested in mathematical reasoning systems. Participants should be respectful, assume good intent, give technically specific feedback, credit other people's work, and make space for different levels of experience.

Harassment, personal attacks, discrimination, doxxing, sexualized conduct, deliberate disruption, and publication of another person's private data are not acceptable. Technical disagreement is welcome; contempt for the person is not.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions, and other public spaces where someone represents this project.

## Enforcement

Maintainers may edit or remove comments and contributions that violate this standard, and may temporarily or permanently restrict participation. Enforcement decisions should be proportionate, documented privately when appropriate, and protect the person reporting harm.

For immediate platform abuse, use GitHub's built-in content reporting tools. For project moderation, contact the repository owner through the contact method shown on their GitHub profile. Do not disclose sensitive personal information in a public issue.
